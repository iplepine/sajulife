# 현재 홈에 맞춘 듀오 디자인 프리뷰

2026-11-15 KST. 대표 요청: 손이 부자연스러운 생성 포스터를 수정하고, 현재 홈에 사용할 수 있게 디자인하며, 로그인 전의 흰 바탕·검정 궁서체 화면과 어울리게 할 것. 후속 질문: 인물 이미지를 넣는 편이 좋은가?

## 실제 화면 확인

현재 앱을 `AI_GENERATION_ENABLED=false`로 로컬에서 실행해 `/`와 `/dashboard`를 실제 브라우저에서 확인했다. 공개 랜딩은 빈 세션, 홈은 기존 E2E 게스트 세션과 시작 전 패키지 GET 응답의 가상 상태로 캡처했다. AI 생성·결제·사용자 데이터 쓰기 없이 UI 구조를 확인했다.

- 기존 화면: `current-landing-390.png`, `current-home-390.png`, `current-home-1440.png`
- 공개 랜딩: 실제 앱과 스타일 원본 모두 수정하지 않았다.

`home.css`의 `--font-ink`는 기존 공개 랜딩과 같은 궁서 폰트 스택이다. 흰 바탕, #111 제목, #555 본문, #e6e6e6 구분선을 사용한다. 캐릭터와 CTA에만 코발트/테라코타를 집중한다. 모바일 5탭과 PC 3메뉴, 세 단계, 완료 풀이 재진입, 보조 서비스·회사 푸터 구조를 유지했다. 검토용 링크는 로컬 앱 `http://localhost:3100`의 실제 기존 경로로 연결한다. 이 파일은 실제 패키지 API를 조회하거나 생성 요청을 하지 않는다.

손/팔이 프레임에 나오지 않는 상반신 조형이다. 두 캐릭터의 정면 시선과 서로 다른 의상색, 사주의 달력·시계 및 기질의 반응 아이콘, 하나로 합쳐지는 초상, 실제 투명 배경을 직접 확인했다.

## 검증 및 권고

- 320·390·768·1440px 가로 넘침 없음. 실행 오류 없음.
- 모바일 390×844에서 CTA 하단은 약 573px로 첫 화면 안에 들어온다. 5탭 표시, PC에서는 5탭 숨김 확인.
- 진행 중/완료/조회 실패 상태의 CTA·완료 단계 재진입·인물 안내창 확인.
- CTA를 실제 클릭해 `/explore/fusion`과 기존 소개 화면 제목으로 도착하는 것 확인. 실제 AI 생성이나 결제는 실행하지 않았다.
- 디자인 권고는 **로그인 후 첫 홈에는 소형 인물 이미지를 넣기**다. 반말의 화자와 두 역할이 읽힌다는 디자인 판단이다. 반복 방문에서는 줄이거나 생략하는 방향을 권고하되 채택 전이다. 이미지 유무에 따른 전환율 효과는 측정하지 않았다.

현재는 대표 검토용 적용 가능한 디자인 소스·리소스다. 실제 `/dashboard` 교체와 배포, 기존 로그인 전 화면 변경, 커밋/푸시는 하지 않았다. 적용 시 현재 `nextJourneyStep`·`isBeforeStart`의 실제 상태 로직을 그대로 연결하고, 새 디자인 문구와 토큰만 검토 범위대로 옮겨야 한다.
