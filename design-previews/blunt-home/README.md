# 홈 디자인과 반말 팩폭 컨셉 정렬

2026-11-15 디자인 제안. 실제 서비스 적용 전.

- `index.html`: 네 방향 선택 및 나란히 비교
- `a.html`: 신윤복 / 다정한 직구
- `b.html`: 김홍도 / 할 말은 하는 내 편 (추천)
- `c.html`: 이중섭 / 솔직한 한 방
- `d.html`: 신사임당 / 근거 있는 한마디

각 파일은 브라우저에서 바로 열 수 있다. 글꼴은 인터넷 연결 시 Google Fonts를 사용하고 오프라인에서는 기본 글꼴로 대체한다. 말투 예시는 가상 상황이며 개인 분석이 아니다. 시작 버튼은 다음 흐름을 설명하는 시안 안내창을 연다.
