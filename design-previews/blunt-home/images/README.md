# 이미지 홈 시안 — 2026-11-15

대표가 기존 HTML 시안의 시각 리소스 부족을 지적하고 이미지 시안을 요청해 별도 제작했다. 기존 HTML을 단순 캡처한 결과가 아니라, 네 방향별 캐릭터·입체 조형·질감이 포함된 새 이미지 디자인이다.

| 파일 | 방향 | 담당 |
| --- | --- | --- |
| `a-warm-sister.png` | 다정한 직구, 수채/과슈 언니 일러스트 | 신윤복 |
| `b-cobalt-advisor.png` | 할 말은 하는 내 편, 코발트 언니와 입체 거울 | 김홍도 |
| `c-candid-tiger.png` | 솔직한 한 방, 블랙·코럴 호랑이 마스코트 | 이중섭 |
| `d-paper-portrait.png` | 근거 있는 한마디, 딥그린 종이 조형 초상 | 신사임당 |

`compare.html`은 네 원본을 나란히 보여준다. `comparison.png`는 이 비교 화면을 캡처한 것이다. 원본 이미지 내용은 수정하지 않았다.

제작 방식: 내장 이미지 생성 도구, 방향별 독립 생성 1회씩 총 4회. 최종 프롬프트는 [prompts.json](prompts.json)에 보관한다. 네 결과 모두 세로형이며 제목·CTA·브랜드·주요 비주얼을 직접 확인했다. 그림 안의 사주 명식/한자/장식 도표는 실제 계산 결과가 아니다. 문구, 단계 표기, 장식 리소스는 최종 제품 구현 시 별도 정렬해야 한다.

이미지 기준 디자인팀 추천은 C: 표정만으로도 친근한 팩폭의 태도가 전달되고, 마스코트를 아이콘·로딩·리포트까지 확장하기 쉽다는 판단이다. A는 사람 캐릭터를 전면에 내세우는 방향, B는 입체 언니 브랜드, D는 분석 신뢰와 조형미를 강조하는 대안이다. 추천은 대표 선택이나 사용자 검증을 대체하지 않는다.

현재 상태: 대표 선택 대기. 실제 제품·기존 디자인 정본·배포에는 미적용.

## 후속 — 두 관점을 함께 읽는 메인 (2026-11-15 KST)

대표가 “사주와 기질을 알 수 있게” 및 “메인에서 사주와 기질을 함께 본다는 걸 어떻게 표현해야 할까?”라고 요청해, 서로 다른 의상의 듀오 v2를 참고하여 하나의 통합 초상을 함께 읽는 홈 이미지 시안을 제작했다.

- [통합 듀오 홈 v1](home-integrated-duo-v1.png)
- [최종 프롬프트](prompt-home-integrated-duo-v1.txt)
- 제작: 내장 이미지 생성 도구 1회. 캐릭터 v2를 정체성과 재질 참고로 사용.
- 표현: 언니는 생년월일·시간과 네 기둥, 오빠는 감정·반응 패턴과 응답 노트를 담당한다. 파랑/테라코타 두 흐름이 같은 책에서 하나의 초상으로 합쳐진다.
- 카피: “타고난 나와, 반응하는 나를 함께.” / “사주 · 타고난 나”, “기질 · 반응하는 나” / 단일 CTA “사주와 기질, 함께 보기”. 하단에는 기존 순서 “사주 풀이 → 기질 검사 → 통합 풀이”를 보여준다.
- 검증: 두 캐릭터 의상 구분, 사주/기질 소품의 차이, 하나의 공유 초상, 핵심 문구와 단계 순서를 직접 확인했다. 그림 속 도표는 실제 개인 사주/검사 결과가 아닌 장식 예시다.
- 상태: 메인 표현 제안 완료, 대표 검토 대기. 제품 화면 미적용.
