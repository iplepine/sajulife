- 범위: B의 코발트 블루·아이보리·입체 종이 조형 스타일을 두 캐릭터로 확장. 홈페이지가 아닌 캐릭터 전신 및 표정 시안.

사주 언니는 살짝 흐트러진 단발, 느슨한 코발트 재킷, 눈썹을 올린 능청스러운 표정, 사주의 네 기둥을 연상시키는 접이식 종이 소품으로 표현했다. 기질 오빠는 단정한 짧은 머리, 안경 없는 얼굴, 아이보리 셔츠와 코발트 니트 베스트, 반응을 관찰하는 노트와 연필로 대비했다. 둘의 피부·머리·의상 재질은 같은 종이 조형 문법을 사용한다.

검증: 생성 이미지에서 두 캐릭터의 전신, 이름, 소품, 각 2개 표정 변주를 직접 확인. 기존 후보 자산과 실제 제품 이미지는 교체하지 않았다. 배경 투명화·분리·경량화·앱 적용은 아직 진행하지 않은 디자인 제안이다.

현재 상태: 요청된 스타일 확장 완료, 캐릭터 최종 채택은 대표 확인 대기.
