# 홈 A/B/C 비교 미리보기

2026-10-31 대표 요청. 운영 홈 교체 전 시각 방향을 비교하는 독립 정적 미리보기다.

- A: 현재 `portrait.html`의 초상 중심 구성.
- B: 입체 명식 — 반투명 석재 네 기둥과 기질 레이더.
- C: 나를 읽는 분석서 — 명식과 기질 도표를 펼친 책.
- 공통: 동일한 헤드라인·CTA·세 단계·보조 메뉴로 비주얼만 비교. 네 계절은 강조색만 변경.
- 접근성: 버튼의 선택 상태, 키보드 포커스, 이미지 설명, 예시/개인 결과 아님 고지.
- 범위 제외: 운영 홈 변경, 로그인, 실제 분석/저장/결제, 자동 배정 A/B 테스트, 사용자 추적.

## 실행

프로젝트 루트에서:

```sh
python3 -m http.server 3190 --bind 127.0.0.1 --directory design-previews/home-types
```

`http://127.0.0.1:3190/?type=a&season=autumn`에서 상단 A/B/C 버튼으로 비교한다. URL에 선택이 유지된다.

## PC·모바일 스크린샷 비교

`http://127.0.0.1:3190/compare.html?type=b`에서 A/B/C별 실제 전체 페이지 캡처를 나란히 비교한다. 이미지를 누르면 원본 크기로 볼 수 있다. 촬영일 2026-10-31, 가을 테마 고정, 로그인/실제 AI 호출 없는 미리보기 화면이다. 정적 촬영본이므로 홈을 수정한 뒤에는 재촬영이 필요하다.

- PC 뷰포트 1440×1000px, 전체 이미지 1440×1314px(A/B/C).
- 모바일 뷰포트 390×844px, 전체 이미지 A/B 390×1346px, C 390×1231px.
- 원본 6개는 `assets/screenshots/`에 보관. 브라우저 스크린샷 API로 직접 촬영했고 이미지 편집/재생성하지 않았다.
- 비교 페이지 검증: A/B/C 각각 양쪽 원본 이미지 로드·URL 전환, 원본 확대와 Esc 닫기, 390px 세로 배치/가로 넘침 없음 확인. 증빙 `output/home-types-2026-10-31/comparison-page.png`.

## 자산

A는 기존 `public/hero-art/self-portrait-v1.webp`를 재사용했다. B/C는 built-in image_gen으로 신규 생성 후 1200px WebP로 최적화했다. 프롬프트는 `PROMPTS.md`에 보관한다. 이미지 내 글자와 차트는 시각 예시이며 실제 서비스의 개인 결과나 검증된 기질 척도가 아니다. 실서비스 채택 시 정확한 명식/척도 라벨은 코드 기반 렌더링으로 별도 정리한다.

## 검증 결과

- 브라우저에서 A/B/C × 320/390/1440px 9개 조합 확인. 가로 넘침 없음, 세 이미지 로드 성공, 타입 전환 시 CTA 좌표 동일.
- 모바일 844px 높이 안에 CTA 표시(320px 너비: 하단 695px, 390px 너비: 하단 741px).
- PC 네 계절 전환 시 헤드라인/CTA 좌표 동일.
- CTA가 개인정보 저장/AI 호출 없는 미리보기 안내를 여는 것 확인.
- `node --check design-previews/home-types/preview.js`, `git diff --check` 통과.
- 증빙 스크린샷: `output/home-types-2026-10-31/`. 별도 정적 화면이므로 Next 빌드/운영 API 테스트는 범위 밖.

### 모바일 여백 조정

C의 정사각 이미지 캔버스를 모바일에서 책의 가로 비율에 맞춰 배치해 내부 여백을 줄이고 책을 확대했다. 공통 모바일 설명/그림/버튼 간격도 축소했다. PC 규격은 유지한다. 320/390/553/1440px에서 가로 넘침 없음. 390px CTA 하단은 741px에서 685px로 올라왔다. 스크린샷 `c-mobile-compact.png`.

A/B도 모바일에서 고정 높이 대신 콘텐츠 폭을 채우는 정사각 프레임(최대 440px)으로 확대했다. 390px 화면에서 그림 폭은 260px에서 346px로 증가하며 원본과 A 지시선은 함께 정렬된다. 320/390/553/1440px A/B 8조합에서 가로 넘침 없음. C/PC 변경 없음. 증빙 `ab-mobile-wide.png`.

### B 기질 그래프 추가

최종 텍스트 처리: SVG 덧씌우기는 대표가 어색하다고 판단하여 제거했다. `assets/pillars-natural-labels-v3.webp`에 ‘기질 / 반응과 행동 성향’과 4축(새로움 추구·위험 회피·사회적 민감성·인내력)을 투명 도표 판에 인쇄된 것처럼 원근/질감과 함께 통합했다. built-in image_gen으로 기존 장면을 편집했으며 원본 v2는 보존했다. 프롬프트 `NATURAL_LABELS_PROMPT.md`. 모바일에서 이미지 로드·덧씌움 제거·가로 넘침 없음 확인. 이미지 대체 텍스트의 설명/예시 고지도 유지. 최신 증빙 `b-natural-labels-mobile.png`.

초기 독립 SVG 영역은 대표 피드백으로 폐기했다. 최종안은 `assets/pillars-integrated-v2.webp`: 기둥 앞 바닥의 투명 판에 4축 그래프가 놓여 동일 원근·재질·빛을 공유하는 단일 장면이다. 받침대 전면의 작은 그래프도 제거했다. built-in image_gen 편집으로 제작했고 원본은 보존했다. 별도 설명 영역/구분선 없이 이미지 안에서 통합하며, 공통 예시 고지는 유지한다. 프롬프트는 `INTEGRATED_B_PROMPT.md`. 320/390/1440px 이미지 로드·가로 넘침 없음·독립 영역 제거 확인. A/C는 변경하지 않았다. 최종 증빙 `b-integrated-mobile.png`, `b-integrated-desktop.png`.
