## 베타 공개 전 필수

- `npm run typecheck` 통과.
- `npm run build` 통과.
- `npm audit --omit=dev`의 high 취약점(현재 Next.js)을 패치 버전으로 업데이트하고 build/E2E 재검증.
- 최소 1명 프로필 입력 -> 개인 리포트 -> 상담 -> 액션 등록 수동 QA.
- 공유 링크가 비로그인 브라우저에서 열리는지 확인.
- 같은 공유 링크를 폐기한 뒤 기존 주소와 OG 주소가 모두 404인지 확인.
- 개인정보/LLM 데이터 사용 안내를 랜딩 또는 온보딩에 최소 고지.
- OpenAI Project API key의 예산 제한·알림, `store: false` 설정, 데이터 사용 조건을 확인하고 Gemini fallback의 paid tier·데이터 사용 조건도 확인.
- Supabase Anonymous Sign-ins와 Email provider 설정 확인.
- 운영 도메인의 Supabase Redirect URL 등록.
- `AI_GENERATION_ACCOUNT_DAILY_LIMIT`과 종류별 한도를 운영 예산에 맞게 설정하고, `AI_GENERATION_ENABLED=false` 킬 스위치 절차를 리허설.
- `E2E_EMAIL`/`E2E_PASSWORD`를 CI secret으로 등록해 전용 스테이징 계정의 공유 lifecycle E2E를 실행.
- 베타 화면에서 티켓 구매·차감 약속이 노출되지 않고, `POST /api/tickets/checkout`이 새 주문을 만들지 않는지 확인.

## 유료 출시 전 필수

- 개인정보 처리방침/이용약관/환불 정책.
- 결제 플로우와 권한 모델.
- 사용자 데이터 삭제 요청 처리.
- 가족 구성원 데이터 입력 동의/고지 강화.
- 계정 전체 데이터 삭제/내보내기와 고객지원 요청 경로.
- 결제·권한·데이터 삭제를 포함한 핵심 API/도메인 테스트 확대.
- 예산 알림과 외부 오류 모니터링 연결.
