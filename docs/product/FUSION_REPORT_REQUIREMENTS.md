# 사주와 기질 최종 리포트 요구사항

마지막 갱신일: 2026-11-03

사주와 기질을 함께 읽는 결과가 서비스의 **최종 리포트**다. 자기 이해와 선택의 방향을 중심으로 구성하며, 올해와 내년 운세는 그 안의 한 부분으로 다룬다. 심리검사에서는 기질 4개와 성격 3개를 구분한다.

이 문서의 심리검사 구분·하위 요소·다섯 융합 항목은 2026-11-02 대표가 제공한 기준이다. 검사 타당성이나 변화 가능성의 정도를 검증한 자료로 취급하지 않으며, 실제 문항·채점·해석에 적용하기 전 전문 검토가 필요하다. 11월 2일에는 요구사항만 기록했고, 11월 3일 후속 승인으로 아래 리포트 구조와 안내를 코드에 반영한다. 검사 문항·채점 산식·저장된 결과는 바꾸지 않는다.

## 최종 리포트 방향

2026-11-06 후속 요청: 개인 사주 v24부터 존댓말을 사주언니·기질오빠의 친근한 반말로 바꾼다. 기존 과장·상투 표현 제한과 11항목 구조는 그대로다. 저장본은 자동으로 수정하지 않는다. 접힌 ‘명리로 보기’를 펼치면 원국 네 기둥이 한 줄에 맞고, 대운은 가로 스크롤 없이 다음 줄로 이어진다. 별도 만세력 원본의 탐색 방식은 유지한다.

대표 요청에 따라 세 독립 편집 관점(출판 편집자·독자/신뢰 리뷰어·명리 해설 독자)을 통합해 [리포트 문체 가이드](REPORT_VOICE_GUIDE.md)를 적용한다. 사주 11항목의 따뜻한 존댓말과 최종 종합 8영역의 차분한 반말을 유지하면서 의무적인 서정 도입·비유 회수·응원형 결말, 반복 추상어·과장된 별명·강점/약점의 기계적인 짝짓기를 덜어낸다. 자연 이미지는 실제 근거에 맞고 설명을 도울 때만 짧게 쓴다.

개인 v23·최종 종합 v32 및 용신/가족/궁합/기존 단독 기질 리포트에 같은 공통 퇴고 기준을 적용한다. 상담 프롬프트는 이번 요청 범위에서 제외한다. 문체를 또렷하게 만든다는 이유로 해석을 확정문으로 바꾸거나 입력에 없는 생활 사건을 만들지 않는다. 필수 항목·수치·명리 근거·날짜·출력 계약·권한은 유지한다. 추가 교정 API 호출이나 자동 문자열 치환은 없으며, 기존 저장본은 그대로 남고 새 생성에만 적용한다. 실제 모델 생성 결과의 말맛은 별도 생성 검수 전까지 미확인이다.

2026-11-03 구현 승인: 사주 정보 입력 → 견본형 사주 리포트 → 기질·성격 검사 → 최종 통합 리포트 순서로 개편한다. 결제·권한과 기존 저장본은 유지한다. 실제 AI 호출 및 운영 배포는 이번 검증 범위에 포함하지 않는다.

사주 리포트는 명식·대운 근거를 유지하면서 타고난 기질과 성격, 강점과 잠재력, 인생의 큰 흐름, 조후 분석, 격국 분석, 억부 분석, 세운 분석, 필요한 것, 행동지침, 인생 로드맵, 성공 조언을 명시적 소제목으로 제공한다. 자연 이미지는 필요한 경우에 쓰고, 사주언니의 따뜻한 반말로 명리 용어의 쉬운 뜻을 병기한다. 견본의 서로 다른 명식을 섞거나 개인별 내용·건강 예언을 복사하지 않는다.

- 사주에서는 타고난 특징과 삶의 흐름을 읽는 관점을 제공한다.
- 심리검사에서는 기질과 성격의 각 특성 및 응답에서 드러나는 반응·행동 성향을 구분해 읽는다.
- 최종 리포트는 둘을 종합해 강점·잠재력·반복 패턴과 나에게 맞는 선택의 방향을 설명한다.
- 올해와 내년 운세는 앞의 자기 이해를 시기에 적용하는 부분이며 최종 리포트 전체를 대체하지 않는다.
- 두 자료가 맞닿거나 다르게 읽히는 부분은 근거가 있을 때만 설명한다. 갈등이나 모순의 개수를 억지로 채우지 않는다.
- 필요한 사주 근거는 최종 리포트에서 짧게 다시 짚을 수 있다. 단독 리포트와의 중복 회피보다 종합 해석의 이해 가능성을 우선한다.
- 개인 사주 신규 출력은 11개 소제목, 최종 통합 신규 출력은 자기이해 중심 8개 영역으로 구성한다. 기질 9항목 예시는 문체·주제 참고로 유지한다.
- 새 개인 사주 출력은 세운 분석의 작년·올해·내년과 제공된 대운 나이 구간별 설명을 검사한다. 새 통합 출력은 8개 영역이 모두 채워져야 하며 다섯 힘을 각각 이름과 본문으로 다룬다. 단독 기질 새 출력도 정해진 8개 영역의 누락·중복·빈 본문을 검사한다. 세 종류에서 복사된 긴 본문 문단은 기존 1회 교정 경로로 보낸다. 저장본 원문은 변경하지 않는다.

이 방향은 2026-10-08 결정의 ‘사주+기질은 올해 운세에 집중한다’는 리포트 목적을 대체한다. 결제·권한·진행 순서 등 다른 제품 정책을 바꾸는 결정은 아니다.

## 최종 화면에서 두 풀이 읽기

2026-11-03 대표 후속 승인으로 `/fusion`에 **종합 풀이 / 사주 풀이** 탭을 둔다. 종합 저장본이 있으면 종합 풀이가 기본이며, 사주 저장본만 있으면 사주 풀이를 먼저 연다. 기질 검사를 마치고 생성을 요청한 진입이나 종합 생성 중에는 종합 탭을 유지한다.

- 탭 전환은 저장된 결과를 보여주는 동작이다. 페이지 이동·새 생성·재결제 없이 전환한다.
- 두 본문을 유지해 탭별 펼친 항목과 읽던 스크롤 위치를 보존한다. 공유는 현재 본문의 종류에 맞춰 별도로 제공한다.
- 종합 풀이 준비가 부족하면 해당 탭에서 기존 정보 입력·기질 검사 안내를 제공한다. 사주 저장본이 없으면 사주 풀이 진입을 안내하고, 조회 실패는 미생성으로 단정하지 않고 조회 재시도를 제공한다.
- 모바일·PC 공통으로 탭을 제공하며 방향키·Home·End로 선택할 수 있다. 기존 단독 `/saju` 경로·저장본·생성 권한은 유지한다.
- 실제 AI 생성·운영 배포 없이 합성 저장본으로 전환과 화면을 검증한다.

## D안 분석 폴리오 — 실제 화면 적용

2026-11-03 대표가 네 독립 디자인 시안 중 **D안(신사임당의 분석 폴리오)**을 선택했다. `/fusion`의 종합·사주 두 읽기 화면에 적용하며, 아래는 승인된 구현 범위다. 이번 개편은 리포트 원문·점수·생성 정책을 바꾸는 작업이 아니다.

- PC는 왼쪽 목차, 중앙의 연속된 해석 본문, 오른쪽의 사주/검사 출처 메모로 구성한다. 모바일에서는 목차를 가로로 탐색하고 핵심 해석부터 읽는다.
- 첫 화면의 큰 제목은 저장된 표제·헤드라인을 우선 사용한다. 첫 요약·문단을 상단에 복제하지 않고 해당 본문에서 한 번만 읽도록 한다. 가상 시안의 인물·문장이나 새로 추측한 개인 해석을 끼워 넣지 않는다.
- 신규 통합 8영역·기존 통합 9영역, 개인 JSON 8/11영역 등 저장된 구조와 원문을 읽는 순간에만 같은 편집형 레이아웃으로 표시한다. 목차는 실제 표시 섹션과 일치시킨다.
- 폴리오의 첫 방문은 본문을 모두 펼쳐 연속해서 읽도록 한다. 기존에 저장한 사용자의 펼침/접힘 선택이 있으면 그 선택을 우선하며, 탭별 읽던 위치와 공유 종류도 유지한다.
- 다섯 가지 힘은 수치가 아닌 해석 관점으로 안내한다. 개인정보 기준표·상세 명리·시기 자료는 본문 뒤의 참고 자료에서 펼친다. 후속 시각 보강 요청으로 실제 명식 네 기둥과 검사 응답 요약은 핵심 해석 아래에 나란히 제공한다. 이전 저장본의 연결·순환 시각 자료도 기본 본문 앞에 노출하지 않고 이전 자료임을 명시해 접어 보존한다.
- 웜화이트·헤어라인·계절 강조색을 기존 토큰과 CSS Module로 구현한다. 단독 `/saju`, 공개 공유 및 디버그 화면의 기본 렌더 방식은 이번 적용 대상이 아니다.
- 문항·채점·프롬프트·API·권한·결제·운영 저장 데이터는 변경하지 않는다. 실제 AI 호출과 배포 없이 PC/모바일, 신규·기존 저장본, 탭·목차·접힘·공유 동작을 검증한다. 검증 결과는 작업 문서에 별도 기록한다.

### 시각 요약과 코칭 등록 UI 제거

- 명식은 실제 계산 자료의 년·월·일·시 네 기둥과 일간을 표시한다. 시각을 모르면 시주는 미상으로 두고, 자료 조회 실패는 명식이 없는 것으로 단정하지 않는다.
- 종합 풀이의 저장된 검사 메타에서 기질 4개(자극추구·위험회피·사회적민감성·인내력), 성격 3개(자율성·연대감·자기초월)의 응답 환산 비율을 막대로 표시한다. 다른 사람 대비 백분위·검증 규준·좋고 나쁨이 아님을 명시한다. 점수가 없거나 잘못됐거나 중복되면 0점이나 추정값으로 대체하지 않는다. 단독 사주 탭에는 검사 요약을 넣지 않는다.
- 대표 요청으로 `/fusion` 하단의 코칭 액션 플랜 등록 목록·등록/전체 등록 버튼을 제거한다. 저장된 액션 데이터·코칭 API·다른 공간의 기능 및 리포트 원문의 실천 방향은 보존한다. 공유와 명시적 다시 생성은 유지한다.

## 사주와 기질의 다섯 융합 항목

대표가 제공한 상징과 키워드, 리포트 항목을 제공 순서에 맞춰 함께 기록한다.

| 상징 | 융합 키워드 | 리포트 항목 |
|---|---|---|
| 큰 나무 | 성장, 개척, 추진 | 목표를 향해 나아가고 변화를 만들어 내는 힘 |
| 타는 불 | 열정, 주도, 표현 | 먼저 행동하고 주변에 에너지를 전달하는 힘 |
| 너른 흙 | 안정, 포용, 지속 | 꾸준히 지탱하고 신뢰를 쌓아 가는 힘 |
| 흐르는 물 | 통찰, 유연, 연결 | 맥락을 읽고 사람과 자원을 연결하며 변화에 적응하는 힘 |
| 단단한 쇠 | 원칙, 결단, 절제 | 원칙을 지키고 상황을 분별하며 중심을 잡는 힘 |

다섯 항목은 사주와 기질을 함께 표현하는 해석 축이다. 아래 심리검사 7개 차원 및 하위 요소와 구분한다. 어떤 응답을 어느 축에 반영할지, 가중치·점수 산식·사주 반영 방식은 아직 정의하지 않았으며 임의로 만들지 않는다. 기존 코드의 오행과 기질 연결표를 이 요구사항의 확정 계산식으로 간주하지 않는다.

## 신규 출력과 저장본 호환

- 개인 프롬프트 v22는 11개 소제목을 순서대로 요구하고 새 생성 파서가 누락·중복·빈 본문을 차단한다. 기존 8개 섹션 저장본은 조회 파서로 그대로 읽는다.
- 단독 개인 사주 화면의 처음 세 항목은 기본으로 펼치고, 사용자가 모두 접은 선택도 보존한다. `/fusion` 안의 D안 폴리오는 위의 전체 펼침 기본값을 따른다. 명식·대운 및 명리 근거 보기는 기존 계산 자료를 쓴다.
- 세운 분석은 화면과 같은 계산 출처에서 작년·올해·내년 근거를 받는다. 견본의 고정된 나이·연도·명식·질병 문장을 복사하지 않는다.
- 최종 프롬프트 v31은 핵심 요약, 다섯 가지 힘의 조합, 사주와 검사 응답, 일과 자원, 관계·스트레스·회복, 성장 과제와 장기 방향, 올해·내년 적용, 실천 방향의 8개 영역이다. 근거 없는 갈등 수량과 미측정 유연성 정수를 강요하지 않는다.
- 같은 출생 정보·명식·판정 기준의 1차 저장본이 있을 때만 핵심 해석 요약을 최종 풀이 참고로 제공한다. 없거나 오래된 근거라면 현재 계산 자료만 사용한다.
- 새 최종 화면은 고정 오행·검사 점수 연결도 대신 다섯 정성 관점의 뜻을 참고로 제공한다. 최초 개편에서 유지했던 과거 통합 저장본의 시각화도 D안 적용 후에는 이전 참고 자료로 접어 보존한다. 신규·과거 저장본 모두 해석을 먼저 읽고 시기 자료는 본문 뒤에서 펼친다.
- 기본 프롬프트 버전을 올려 이전 KV 프롬프트보다 새 기준을 선택하게 한다. 운영 데이터 수정·기존 결과 일괄 재생성·배포는 하지 않는다. 실제 모델 출력 품질은 별도 생성 검수 전까지 미확인이다.

## 기질 리포트 예시

대표가 제공한 [기질 리포트 9개 항목 예시](TEMPERAMENT_REPORT_EXAMPLE.md)를 원문 그대로 별도 보존한다. 목차는 다음과 같다.

1. 기본 성향과 다섯 가지 기질의 조합
2. 기질의 핵심과 성격적 특징
3. 일하는 방식과 성과가 나는 환경
4. 자원 관리와 소비·축적 습관
5. 관계에서 드러나는 강점과 갈등 패턴
6. 스트레스 신호와 회복 방식
7. 시기별 성장 과제와 변화의 방향
8. 장기적 성장 전략과 지속 가능한 삶
9. 핵심 기질 요약과 실천 방향

이는 대표가 ‘기질 리포트의 예시’로 제공한 구성과 문체다. 다섯 융합 축과 아홉 서술 항목은 서로 다른 구조이며, 이 예시만으로 최종 통합 리포트의 목차를 아홉 개로 확정하거나 단독 기질 리포트의 운영 재개를 결정하지 않는다. 예시의 ‘다섯 가지 기질’이라는 표현은 원문을 보존하며 검사 7개 차원과의 명명 관계는 후속 설계에서 정리한다.

## 심리검사의 핵심 구분

아래는 대표가 제공한 변화 특성의 구분이다.

| 구분 | 포함 차원 | 제공된 기준 |
|---|---|---|
| 기질 | 자극추구, 위험회피, 사회적민감성, 인내력 | 잘 변하지 않음 |
| 성격 | 자율성, 연대감, 자기초월 | 스트레스 상황에 따라 변할 가능성 많음 |

일곱 차원을 모두 ‘지금 상태를 재는 최신 값’으로 묶지 않는다. 단일 응답만으로 과거 대비 변화나 스트레스에 의한 변화를 확인했다고 해석하지 않는다.

## 기질의 하위 요소

대표가 적은 양극의 순서를 유지했다. 아래 항목은 하위 요소의 개념 기록이며 실제 검사 문항이나 점수 계산식이 아니다.

### 자극추구

| 순서 | 왼쪽 극 | 오른쪽 극 |
|---|---|---|
| 1 | 관습적 안정성 | 탐색적 흥분 |
| 2 | 심사숙고 | 충동성 |
| 3 | 절제 | 무절제 |
| 4 | 질서정연 | 자유분방 |

### 위험회피

| 순서 | 왼쪽 극 | 오른쪽 극 |
|---|---|---|
| 1 | 낙천성 | 예기불안 |
| 2 | 낮은 불확실성에 대한 두려움 | 높은 불확실성에 대한 두려움 |
| 3 | 낮은 낯선 사람에 대한 수줍음 | 높은 낯선 사람에 대한 수줍음 |
| 4 | 활기 넘침 | 쉽게 지침 |

### 사회적민감성

| 순서 | 왼쪽 극 | 오른쪽 극 |
|---|---|---|
| 1 | 낮은 정서적 감수성 | 높은 정서적 감수성 |
| 2 | 낮은 정서적 개방성 | 높은 정서적 개방성 |
| 3 | 거리두기 | 친밀감 |
| 4 | 독립 | 의존 |

### 인내력

| 순서 | 왼쪽 극 | 오른쪽 극 |
|---|---|---|
| 1 | 낮은 근면 | 높은 근면 |
| 2 | 낮은 끈기 | 높은 끈기 |
| 3 | 낮은 성취야망 | 높은 성취야망 |
| 4 | 낮은 완벽주의 | 높은 완벽주의 |

## 성격의 하위 요소

### 자율성

| 순서 | 왼쪽 극 | 오른쪽 극 |
|---|---|---|
| 1 | 낮은 책임감 | 높은 책임감 |
| 2 | 낮은 목적의식 | 높은 목적의식 |
| 3 | 낮은 유능감 | 높은 유능감 |
| 4 | 낮은 자기수용 | 높은 자기수용 |
| 5 | 낮은 자기일치 | 높은 자기일치 |

### 연대감

| 순서 | 왼쪽 극 | 오른쪽 극 |
|---|---|---|
| 1 | 낮은 타인수용 | 높은 타인수용 |
| 2 | 낮은 공감 | 높은 공감 |
| 3 | 낮은 이타성 | 높은 이타성 |
| 4 | 낮은 관대함 | 높은 관대함 |
| 5 | 낮은 공평 | 미완성 — 원문이 ‘높은’에서 끝남 |

마지막 항목의 원문 끝은 `낮은공평-높은`이다. 오른쪽 극은 추가 제공 전까지 임의로 완성하지 않는다.

### 자기초월

성격 차원에 포함된다는 구분만 제공됐다. 하위 요소는 아직 제공되지 않았다.

## 후속 확인 사항

- 연대감 마지막 항목의 완전한 양극 표현과 자기초월 하위 요소를 추가로 기록한다.
- 제공된 구분·용어와 변화 특성을 전문 자료 및 전문가 검토로 확인한다.
- 현재 자체 제작 약식 35문항이 각 하위 요소를 얼마나 다루는지 점검한다. 차원 점수만으로 없는 하위척도 점수를 추정하지 않는다.
- 기존 서비스 표시명과 여기 기록한 차원명을 연결하는 명명 기준을 별도로 정한다. 이번 기록만으로 서비스 용어를 변경하지 않는다.
- 변화 해석에 필요한 이전 응답, 응답 시점 및 상황 정보의 범위를 정한다.
- 다섯 융합 축과 심리검사 7개 차원·하위 요소를 연결할 해석 근거 및 산식을 정한다. 제공된 기질 리포트 예시와 최종 통합 리포트의 관계도 함께 설계한다.
