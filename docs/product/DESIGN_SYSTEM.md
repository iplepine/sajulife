# 디자인 가이드

마지막 갱신일: 2026-07-17

> 상위 문서: [DESIGN_PRINCIPLES.md](DESIGN_PRINCIPLES.md) — 계절 컨셉 전면 개편의 **왜·무엇**. 판단이 갈리면 원칙 문서가 이긴다.
> 이 문서는 그 원칙을 실제 토큰·수치·컴포넌트 규격으로 옮긴 **어떻게**다.

이 문서는 `사주언니 x 기질오빠` 컨셉을 제품 UI에 적용할 때의 기준이다. 목적은 캐릭터성은 살리되, 리포트 본문이 장난감처럼 보이지 않게 프리미엄 상담 문서의 밀도를 유지하는 것이다.

## 브랜드 톤

- 사주언니: 사주를 먼저 잡아주는 친근한 해석자. 말은 직설적이지만 사용자를 비웃지 않는다.
- 기질오빠: 기질과 행동 패턴을 정리해주는 현실적인 조력자. 차분하고 실용적인 느낌을 맡는다.
- 둘의 조합은 `사주언니 x 기질오빠`로 표기한다. UI에서는 곱하기 기호보다 `x`를 기본으로 쓴다.
- 배경은 따뜻한 아이보리 계열을 유지하고, 본문 텍스트는 검정/짙은 회색 중심으로 둔다.
- 캐릭터 이미지는 반복 노출하지 않는다. 리포트 상단 또는 대표 카드에서 한 번 강하게 쓰고, 반복 섹션에서는 텍스트와 컬러 신호로 구분한다.

## 개인 흐름 계절 테마

앱 전역 테마는 로그인한 인물의 현재 대운 지지(대운이 없으면 월지)에서 계산한 계절을 따른다. 사주 정보가 아직 없거나 로그인 전에는 달력 계절을 안전한 기본값으로 쓴다. 이 테마는 운세 결과나 좋고 나쁨을 표시하는 장치가 아니라, 사용자가 지금 보는 인생 흐름에 맞춘 환경색이다.

인물을 전환하면 선택 즉시 해당 인물의 계산된 계절 토큰을 적용하고, 200ms 이내의 표면색 전환만 사용한다. 전환 API가 같은 테마를 쿠키로 저장해 새 화면도 첫 페인트부터 해당 색으로 시작하므로, 달력 계절로 잠깐 돌아갔다가 차트 응답 후 다시 바뀌는 플래시는 허용하지 않는다. `prefers-reduced-motion`에서는 즉시 전환한다.

| 토큰 역할 | 봄 | 여름 | 가을 | 겨울 |
|---|---|---|---|---|
| 캔버스/앱 바탕 | 벚꽃 아이보리 | 옅은 하늘빛 | 살구 베이지 | 푸른 회백 |
| 대표 행동/링크 | 코랄 로즈 | 맑은 블루 | 앰버 브라운 | 인디고 |
| 표면/카드 | 분홍 기운의 화이트 | 푸른 기운의 화이트 | 금빛 기운의 화이트 | 라일락 기운의 화이트 |
| 히어로 구슬/페이드 | 로즈 | 아쿠아 | 골드 | 오로라 블루 |

- 전역 CSS는 `data-season-theme`와 의미 토큰 `--bg`, `--surface`, `--surface-2`, `--border`, `--link`, `--btn-bg`, `--season-accent`를 사용한다. 화면이나 컴포넌트에서 계절 색상값을 직접 쓰지 않는다.
- 계절 테마는 앱 바탕, 카드·입력 표면, 기본 버튼, 링크, 활성 탭/사이드바 상태, 히어로 페이드에 적용한다.
- 오행·사주 계산값·리포트 섹션처럼 데이터 의미가 있는 색은 계절 테마로 바꾸지 않는다. 사용자는 계절색을 개인 결과로 오해해서는 안 된다.
- 활성 인물을 바꾸면 기존 화면을 새로고침하므로 전역 테마도 함께 다시 계산한다.

## 홈 화면

- 홈은 기능 설명서가 아니라 다음 행동을 고르는 시작 화면이다.
- 홈 상단은 `사주로 나를 읽고, 다음 선택을 설계한다`는 인생 컨설팅의 첫 장면으로 둔다. 사주 풀이 자체가 아니라 지금의 고민을 다음 선택으로 연결하는 것이 대표 행동이다.
- 상단 히어로는 현재 계절(봄·여름·가을·겨울)에 맞는 사람 없는 갈림길 풍경 1장을 사용한다. PC용은 16:9 와이드 원본으로, 모바일은 같은 원본의 중앙 9:16 안전영역을 좌우 크롭해 쓴다. 길이 둘로 나뉘는 지점은 화면 중앙에 두며, 제목은 상단, CTA는 하단에 배치해 갈림길을 가리지 않는다. 겨울 풍경은 오로라를 쓸 수 있다.
- 계절 배경은 순수 풍경만으로 만든다. 천간 노드·원형도·글자·인물은 배경에 그리지 않고, 필요할 때만 UI 레이어에서 별도로 배치한다.
- 중앙 구슬은 봄·여름·가을·겨울별로 준비한 투명 PNG 리소스를 쓰고, 한자는 코드 텍스트로 그 위에 올린다. 중앙 한자는 활성 인물의 일간을 쓰며, 사주 정보가 아직 없을 때만 계절 기본 글자로 fallback한다. 따라서 구슬의 빛·질감은 배경 이미지와 독립적으로 바꿀 수 있다.
- 구슬과 바깥 노드를 잇는 리소스는 방사형 연결선 없이 얇은 점선 궤도와 중앙 세로 축만 쓴다. 이 SVG는 계절별 강조색으로 각각 준비하며, 배경과 합치지 않아 계절별 구슬·노드 위치를 바꿔도 재사용할 수 있어야 한다.
- 바깥 한자는 중앙 일간을 돋보이게 하는 8개 보조 기호로만 배치한다. 분석 전에는 개인의 천간·용신·오행 수치처럼 보이는 결과를 보여주지 않는다.
- 히어로의 CTA는 프로필 전에는 `내 인생 흐름 읽기`, 리포트가 있으면 `지금 고민 상담하기`로 연결한다. 계절은 자동 롤링 배너가 아니라 해당 시점의 한 장면으로 고정한다.
- 배너 아래 리포트 목록은 제목과 이동 화살표만 보여준다. 기능별 상세 설명을 반복하지 않는다.
- 사주언니 x 기질오빠 캐릭터 이미지는 이 홈 히어로에 쓰지 않는다. 캐릭터가 필요한 경우에도 리포트 상단 등 대표 영역에서 한 번만 사용하고, 리포트 목록 카드에서는 반복하지 않는다.
- 리포트 진입 카드는 긴 말투 문장을 쓰지 않는다. 제목 1줄, 설명 1줄, 상태/행동만 남긴다.
- `35문항`처럼 특정 검사 문항 수를 홈 카드에 고정 노출하지 않는다. 약식/정식 등 여러 검사 종류가 있을 수 있기 때문이다.
- 모바일에서 제목은 17px 이상, 설명은 14.5px 이상을 기본으로 하여 홈 첫 화면에서 작게 보이지 않게 한다.
- 큰 검은 CTA 버튼은 상단 대표 행동에만 쓰고, 반복 카드 안에서는 카드 전체 클릭과 짧은 `보기 ->` 류의 행동 표시를 우선한다.
- 계절 이미지는 풍경·빛·온도만 바꾸며 결과의 좋고 나쁨, 개인 운세, 실제 오늘의 기운을 암시하지 않는다.

## 입력 폼

- 프로필 수정, 가족 추가, 검사 설정처럼 사용자가 직접 고르는 화면은 작은 보조 텍스트보다 입력값 가독성이 우선이다.
- 모바일 폼 컨트롤의 입력값/선택값은 18px 안팎을 기준으로 한다.
- 필드 라벨은 14.5px 이상, 굵기는 700 수준으로 두어 긴 화면에서도 항목 구분이 바로 보이게 한다.
- 세그먼트 버튼은 최소 48px 높이를 유지해 터치 영역과 글자 크기를 함께 확보한다.
- 생년월일/출생시각처럼 중요한 프로필 값은 브라우저 native date/time 입력을 그대로 쓰지 않는다. 큰 표시 필드를 누르면 바텀시트 피커가 열리는 방식으로 통일한다.
- 생년월일은 `연도 -> 월 -> 일` 단계로 고르고, 출생시각은 `오전/오후 + 시 + 분`을 고르는 화면을 쓴다. 선택 결과는 `1990. 06. 14.` / `오전 07:15`처럼 사람이 읽는 형태로 표시한다.

## 리포트 섹션 컬러

리포트 하단 접힘 섹션은 모두 같은 붉은 포인트를 쓰면 반복 카드처럼 보인다. 섹션별 성격을 구분하기 위해 톤다운한 빨주노초파남보 계열의 포인트 컬러를 쓴다.

적용 원칙:

- 제목 전체 색을 바꾸지 않는다. 제목과 본문은 읽기 좋은 검정/회색을 유지한다.
- 컬러는 왼쪽 세로 막대, 작은 점, 얇은 상단 라인 같은 보조 신호에만 쓴다.
- 원색 무지개, 그라데이션, 과한 배경색은 쓰지 않는다.
- 같은 리포트 안에서 색은 섹션의 의미를 빠르게 스캔하게 하는 용도다. 감정 톤을 과장하지 않는다.
- 공유 페이지와 모바일에서도 같은 매핑을 유지한다.

권장 매핑:

| 섹션 계열 | 컬러 역할 | 권장 색 |
|---|---|---|
| 오행구성 / 기질구성 | 전체 에너지, 구성, 시작 | 초록 `#2F8B6B` |
| 기본성향 | 핵심 성향, 자기 이해 | 코랄 `#C95C55` |
| 직업운 | 실행, 일, 생산성 | 주황 `#D28B2D` |
| 금전운 / 가족금전운 | 돈, 자원, 관리 | 골드 `#C69A2A` |
| 인간관계운 / 가족분위기 | 관계, 연결, 대화 | 청록 `#2E9A8F` |
| 건강운 / 가족건강운 / 스트레스관리 | 회복, 몸, 조절 | 파랑 `#3F73B5` |
| 대운 / 가족대운 별 비교 / 인생 시기 | 큰 흐름, 장기 관점 | 남색 `#344F86` |
| 올해 실행전략 | 전략, 전환, 실행 계획 | 보라 `#7B5AA6` |

## 브랜드 아이콘

- 왼쪽 사이드바와 모바일 하단 탭의 아이콘은 작은 크기에서 먼저 읽혀야 한다.
- 아이콘 선은 두껍게 강조하지 않는다. 기본 SVG stroke는 1.6~1.7px 수준을 유지한다.
- 내부 디테일이 많은 아이콘은 작은 메뉴에서 뭉치므로, 선 수를 줄이고 실루엣을 먼저 보이게 한다.
- 아이콘 컨테이너는 은은한 배경/테두리로 버튼성을 만들고, 아이콘 자체는 컨테이너 안에 60~70% 크기로 배치해 여백을 둔다.
- 캐릭터 얼굴 아이콘은 리포트 상단 같은 대표 영역에만 쓰고, 반복 메뉴에서는 단순 벡터 아이콘을 우선한다.

## 한줄문구 강조

- 개인 사주 상단 대표 문장은 AI 리포트 JSON의 `title`을 우선 사용한다. 아직 리포트가 없거나 옛 저장본처럼 `title`이 없으면 일간/계절/띠 계산값으로 만든 문구를 fallback으로 보여준다.
- 한줄문구는 말풍선이 아니라 리포트형 강조문으로 보인다.
- 큰따옴표를 실제 텍스트로 붙이지 않는다.
- 박스 테두리는 약하게 하거나 제거하고, 컬러 포인트는 왼쪽 막대 중심으로 둔다.
- 접힘 섹션 안에서는 카드 안 카드처럼 보이지 않게 배경 대비를 낮춘다.
- 섹션 요약은 모두 `~결`로 끝나지 않게 프롬프트에서 제한한다.

## 리포트 본문 글꼴

- 접힘 섹션의 긴 해설 본문은 고전 문서처럼 보이지 않게 `Gowun Dodum` 우선의 브랜드 돋움 계열을 쓴다.
- 섹션 제목은 캐릭터성을 유지하기 위해 브랜드 세리프를 쓸 수 있지만, 본문 전체를 명조로 두지 않는다.
- 모바일 본문 크기는 16px 안팎을 기준으로 하고, 줄간격은 1.75~1.8 수준으로 유지한다.
- 본문 크기를 키워 강조하기보다 섹션 제목, 요약문, 여백으로 위계를 만든다.

## 인생 시기 그래프 문구

- LifeCircle의 위/아래 축은 좋고 나쁨이 아니라 힘이 오는 방향을 설명하는 보조 기준이다. 리포트의 메인 해석처럼 크게 강조하지 않는다.
- `도움받는 시기 / 책임지는 시기`처럼 도덕 평가로 읽힐 수 있는 말은 피한다.
- 위쪽은 `주변에서 도와주는 시기`로 설명한다. 사람·환경·기회가 힘을 보태는 구간이라는 뜻이다.
- 아래쪽은 `내가 스스로 해내는 시기`로 설명한다. 선택·일·역할을 내가 잡고 가는 구간이라는 뜻이다.
- 이 축은 안내 박스 안의 읽는 법으로만 설명하고, 그래프 하단 요약 문장에서는 반복 강조하지 않는다.
