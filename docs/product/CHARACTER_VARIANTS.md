## 적용 전 기준

### 2026-11-15 코발트 종이 조형 듀오 후보

대표가 홈 이미지 시안 2번(B)의 느낌으로 사주 언니·기질 오빠를 새로 디자인하도록 요청했다. 코발트 블루·아이보리와 입체 종이 조형을 공유하되, 언니는 능청스러운 단발·느슨한 재킷, 오빠는 안경 없이 단정한 머리·니트 베스트·관찰 노트로 구분했다. 각 캐릭터 전신과 표정 2종을 한 시트에 담았다.

- [듀오 캐릭터 v1](../../design-previews/blunt-home/images/characters/saju-unni-gijil-oppa-cobalt-v1.png)
- [제작 기록과 프롬프트](../../design-previews/blunt-home/images/characters/README.md)
- 상태: 스타일 확장 시안, 최종 채택 대기. 기존 이미지 미교체.

### 공통 적용 기준

- 홈 히어로에는 1장만 사용한다.
- 반복 카드나 메뉴 아이콘에는 캐릭터 이미지를 반복하지 않는다.
- 기질오빠 기본 방향은 안경/추리닝 없이 단정한 호감형으로 둔다.
- 사주언니는 과하게 망가지지 않게 생활감 있는 B급 톤까지만 사용한다.
- 실제 교체 전에는 선택본 1장을 WebP/PNG로 경량화한 뒤 적용한다.
- 작은 아이콘으로 쓰려면 별도 크롭 버전을 만든다.
