# 신뢰와 개인정보 원칙

마지막 갱신일: 2026-08-07

## 다루는 데이터

현재 앱은 다음 개인 데이터를 다룬다.

- Supabase 사용자 식별자와 이메일.
- 이름 또는 별명.
- 생년월일, 출생 시각, 양/음력, 성별.
- 사용자가 남긴 메모.
- TCI 응답과 점수.
- 가족 구성원의 이름, 관계, 생년월일, 출생 시각, 양/음력, 성별.
- 리포트 본문, 상담 질문/답변, 코칭 액션.
- 공개 공유 스냅샷.

## 저장 위치

- 인증 세션과 이메일 계정은 Supabase Auth가 관리한다.
- 제품 데이터는 Upstash Redis KV에 `user:{userId}:...` 네임스페이스로 저장한다.
- 공개 공유 링크는 `share:{token}` 키에 자기완결 스냅샷과 발급·만료·폐기 시각을 저장한다.
- 프롬프트 override는 전역 `prompts` 키에 저장한다.

## LLM 전송 범위

기본 OpenAI 호출에는 기능별로 다음 데이터가 포함된다. OpenAI의 일시 장애(408/429/5xx·네트워크 오류) 때만 같은 입력을 Gemini fallback에 한 번 전송할 수 있다. 잘못된 요청이나 안전 정책 거절은 fallback에 재전송하지 않는다.

- 개인 사주 리포트: 프로필, 계산된 사주표, 대운/오행/음양한열, 메모.
- 기질 리포트: 이름, 성별, TCI 점수.
- 융합 리포트: 프로필, 계산된 사주표, TCI 점수.
- 가족 리포트: 본인 프로필/사주, 가족 구성원 프로필/사주.
- 상담: 질문, 저장된 리포트 요약. 리포트가 없으면 상담을 생성하지 않는다.
- 상담 근거 요약: 리포트 본문 일부 또는 전체.

OpenAI Responses API 요청은 `store: false`로 보내고, 정책 위반 탐지에는 원래 사용자 ID 대신 해시된 안정 식별자만 사용한다. Gemini fallback의 paid tier·데이터 사용 조건도 별도 확인이 필요하다. 외부 베타 또는 결제 사용자 전환 전에는 두 공급자의 데이터 사용 조건과 개인정보 처리방침을 확정해야 한다.

베타 UI에서는 랜딩과 사주 정보 입력 전에 OpenAI 기본 전송과 Gemini fallback 가능성을 안내한다. 가족 정보 입력 전에는 입력·보관 권한이 있는 정보만 넣도록 안내하고, 가족 리포트 생성 시 선택한 구성원의 정보와 관계 맥락이 두 공급자 중 실제 생성 공급자에 전송될 수 있음을 고지한다.

## 공개 공유 정책

- `/share/{token}` 링크는 인증 없이 열린다.
- 링크를 아는 사람은 누구나 해당 리포트 스냅샷을 볼 수 있다.
- 링크는 기본 30일 뒤 만료하며, 사용자가 명시적으로 `만료 없음`을 선택할 수 있다.
- 소유자는 현재 링크의 만료일을 보고 즉시 폐기하거나 새 링크를 재발급할 수 있다. 재발급은 이전 주소를 즉시 무효화한다.
- 만료·폐기·손상된 스냅샷은 공개 페이지와 OG 이미지 모두에서 존재하지 않는 링크처럼 처리한다.
- 추가 인물을 삭제하기 전 해당 인물의 공개 링크를 먼저 폐기한다.
- 모든 리포트 공유는 링크 생성 전에 인증 없는 공개 링크임을 확인받는다.
- 가족 리포트 공유는 타인의 출생 정보와 관계 해석이 포함될 수 있어 별도의 추가 경고를 보여준다.
- 가족 정보가 리포트 생성 이후 바뀐 경우, 새 기준으로 리포트를 다시 생성하기 전에는 가족 리포트 공유를 막는다.

## 해석 신뢰 원칙

- 만세력 계산은 LLM이 아니라 `lunar-javascript` 결과를 사용한다.
- LLM에는 계산된 값을 인용하게 하고, 재계산하지 못하게 프롬프트에서 제한한다.
- 사주, 기질, 가족 해석은 자기 이해/상담 콘텐츠이지 의료, 법률, 투자, 안전 판단을 대체하지 않는다.
- 반말 팩폭 톤을 쓰더라도 모욕, 공포 조장, 가족 구성원 비난은 금지한다.

## 제품화 전 필수 작업

- 개인정보 처리방침과 이용약관 작성.
- OpenAI Project API key의 예산·알림·데이터 사용 조건과 Gemini fallback paid tier 조건 확정.
- 사용자 데이터 삭제 요청 처리 경로.
- 가족 구성원 데이터 입력에 대한 명시 고지.
- 결제 전환 시 이메일 확인, 환불, 고객지원 정책.
