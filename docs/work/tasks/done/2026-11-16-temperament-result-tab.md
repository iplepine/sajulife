최종 결과 `/fusion`의 기존 종합 풀이·사주 풀이 옆에 기질 검사 탭을 추가한다. 완료 응답으로 계산한 기질 4개·성격 3개의 점수/설명을 보여주고, 기존 기질 AI 해설이 있으면 당시 점수·해설을 함께 읽는다. 새 사용자에게 기질 AI 저장본이 없는 것이 정상인 현재 흐름을 고려해 점수만으로도 결과를 제공한다. 부분 응답은 완료 결과로 표시하지 않는다. 과거 해설에 현재 응답 점수를 섞거나 없는 점수·유연성을 만들지 않는다.

시각 방향은 기존 명조·중립 표면·계절 강조색과 A/B 디자인을 유지한다. 상단 세 탭 → 검사 경향 → 저장 해설 순서로 읽고, 전환 시 읽던 위치/펼침 상태와 키보드 선택을 보존한다. 조회 실패는 독립 GET 재시도로 복구하고 저장본/완료/미완료/진행 상태를 구분한다.

출력/저장/문항/채점/권한/결제 정책과 기질 단독 AI 신규 생성 비활성화는 유지한다. 방문·탭 전환으로 POST·추가 AI·공유 발급을 시작하지 않는다. 실제 AI·운영 데이터 변경 없이 합성 API 응답으로 PC/모바일, 전환·키보드·빈/실패/이전 저장본·POST 0회를 검증한다. 이번 task에 커밋·푸시·배포는 포함하지 않는다.

## 후속 — 모바일 하단 메뉴와 A/B 개별 디자인 (2026-11-16 KST)

대표가 전체 페이지 캡처에서 하단 메뉴가 중간에 보이는 점과 A/B별 디자인 적용 여부를 확인했다. 첫 구현은 공통 결과 구성에 기존 A/B 테마를 적용한 것이며 새 기질 탭의 B 전용 표현까지 다듬은 상태는 아니었음을 알렸다.

A는 기존 차분한 리포트 구성·계절 강조색·흑백 안내를 유지했다. B는 승인된 기질오빠 아트를 재사용한 전용 안내, 테라코타 강조선/옅은 배경과 궁서 제목을 적용했다. B에서는 옛 흑백 안내 아이콘을 중복 표시하지 않는다. 공통 점수·차원 의미색·데이터는 동일하게 읽는다. `CharacterMessage`로 기존 캐릭터 안내 마크업을 재사용하며 다른 B 경로의 안내 동작은 유지한다.

하단 메뉴는 원래 `position: fixed; bottom: 0`이고 부모에 고정 기준을 바꾸는 transform/contain이 없었다. 긴 full-page 캡처에서 뷰포트 고정 요소가 문서 중간에 한 번 보인 것이 원인이었으며, 실제 위치 오류는 재현되지 않았다. 셸의 하단 고정 CSS는 변경하지 않았다. 전달용 모바일 캡처를 전체 페이지 대신 실제 뷰포트 크기로 다시 만들었다.

- 최신 단위 테스트 101/101, 타입·변경 파일 lint·빌드 통과.
- 신규 기질 탭 시나리오 16건 + 기존 A/B 시나리오 4건 = 20/20 통과. 320×740·390×844에서 A/B 각각, 1440px PC도 A/B 각각 검증했다.
