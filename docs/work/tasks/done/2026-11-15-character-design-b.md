## 승인된 범위

대표 정정: A는 현재 실제 서비스 그대로, B는 이번 새 캐릭터 디자인으로 전체 화면 개편. 추가 지시: “B는 캐릭터 중심 안으로 해줘.” 기존에 시안 두 개를 A/B로 비교한 산출물은 이 요청을 충족하지 못하므로 폐기 대신 오해된 중간안으로 기록을 보존한다.

A를 기본으로 유지하고 명시적으로 B를 선택할 때 새 디자인이 실제 앱의 주요 내부 화면에 이어지도록 한다. 로그인 전 `/` 흰 바탕·검정 궁서체는 고정한다. 사주 언니 코발트·기질 오빠 테라코타, 정면 시선, 손 없는 캐릭터를 사용하고 홈은 두 인물이 중심이다. 입력·검사·리포트·자료·상담·가족·계정은 같은 스타일과 역할별 안내로 확장한다.

## 동작과 제외 범위

- 디자인 선택은 `?design=a|b`와 브라우저 선호로 유지. 검토 페이지에서 두 안을 고를 수 있다.
- 실제 기능·데이터·API·검사 점수·명리 계산·AI 프롬프트·생성 의사·결제·공유 권한은 유지한다.
- 사주→기질→통합, 진행/오류/재시도 상태와 재진입 경로는 기존 로직을 그대로 사용한다.
- 실제 트래픽 무작위 배정·방문자 추적·외부 배포·커밋·푸시 없음.

## 완료 기준

- A 기본 화면 및 공개 랜딩의 DOM/주요 스타일이 기존과 동일하다.
- B 홈 캐릭터 주도 구성, 역할별 공통 안내와 주요 화면 공통 스타일이 실제 페이지에 적용된다.
- B를 선택한 뒤 내부 링크 이동 시 유지되고 A로 되돌릴 수 있다.
