# 홈 사주 + 기질 렌즈 디자인 반영

- 승인: 2026-10-13 대표가 A안 3D 렌즈 시안의 실제 홈 반영 요청.
- 범위: 홈 히어로만 변경. 인물 선택, 진행 단계, 결제·생성 경로, 계절 테마, 보조 기능은 유지.
- 구성: 대각선 두 렌즈, 각각 원 중심의 사주·기질 아이콘, 교집합의 ‘나’, 아래 플로팅 버튼.
- 명식 아이콘: 년월일시의 8칸에 서로 다른 천간·지지와 물음표를 넣은 상징. 실제 개인 결과 아님을 대체 텍스트로 명시.
- 기질 아이콘: 서비스 용어인 추진성·안정성·공감성·지속성의 네 축. 예시 도형이며 개인 점수가 아님.
- 초기 버튼: ‘사주와 기질, 한 번에 보기’. 이미 진행 중이면 기존 다음 단계·오류 복구 문구 유지.
- 검증: 타입 검사, 진행 단계별 홈 E2E, 모바일·PC 중심 좌표/가로 넘침/버튼 간격 검사.
- 결과: 타입 검사 통과, 홈 E2E 12개 및 반응형 좌표 검사 1개 통과. 390px·1440px 실제 홈 스크린샷 확인.
- 제외: 커밋, 푸시, 배포. 사용자 요청 시 별도 진행.
- 하단 추가 승인: 시안처럼 ‘다른 궁금함도 있다면’ 아래 가족 사주·궁합·용신 풀이·고민 상담의 네 링크를 배치. 기존 퀵메뉴/추천 배너를 대체하며 각 진입 주소와 정책·회사 정보는 유지.
