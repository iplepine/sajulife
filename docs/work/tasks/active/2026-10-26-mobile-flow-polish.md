# 새 메인 디자인과 실제 모바일 흐름 정리

- 승인: 대표가 사주 결과의 코칭 담기 제거와 새 디자인에 맞춘 실제 기능·모바일 사용성 정리를 요청.
- 사주: 코칭 액션 플랜 등록 카드만 제거. 기존 후보·저장 데이터·코칭 API·다른 결과의 등록 기능은 보존.
- 탐색: 모바일에 내 풀이 탭 추가(5탭). 사주·기질·통합·자료 경로는 내 풀이 그룹으로 활성화. 가족·상담·마이 진입 유지.
- 인물: 공통 헤더는 실제 인물 이름 표시. 11개 결과/자료 화면 제목의 중복 선택기 제거. 결제 대상 확인·소개 화면의 명시적 변경 경로는 유지. 상담 인물 변경 시 기존 대화 주소를 지우는 동작 보존.
- 모바일: 긴 이름 말줄임, 320px 인물 메뉴 위치·높이·스크롤, 44px 알림 터치 영역, 입력 16px, 새 하단 탭의 이동/그림자 제거. 초상 배경 타원 보정.
- 홈: 예전 9개 조회 중 사용하지 않는 조회 제거. `/api/package`가 프로필/진행 여부의 단일 정본. 12초 제한과 취소, 실제 재조회 버튼과 중복 클릭 방지. 실제 읽기에서 정상 프로필 응답이 4,823ms여서 예전 4초 제한을 초과한 사례 확인. 데이터 없음으로 오인하거나 유료 권한을 우회하지 않음.
- 설문: 모바일 다음 문항 미리보기 숨김으로 현재 질문/응답/이동 버튼 우선. 저장·자동 진행·올해 운세 연결은 유지. 선택색과 키보드 초점을 공통 계절 강조색으로 통일.
- 검증: 최종 빌드/타입 검사 통과. PC·모바일 공통 경로·홈 상태·사주 재방문 E2E 81개 통과. 추가 패키지 한 바퀴/기질 저장 검증 6개 통과, 서버 부분 응답 검증 1개는 기존 조건으로 건너뜀. 최종 설문 UI 보정 후 모바일 설문·320px 인물 메뉴·반응형/계절 불변 검사 3개 재통과. 변경 파일 ESLint 오류 없음(사주 페이지의 기존 generate 의존성 경고는 별도).
- 실제 계정: 모바일 홈에서 오류 CTA 대신 내 올해 운세 보기와 완료 단계 표시 확인. 사주 결과에 코칭 카드/제목행 선택기 없음, 내 풀이 활성, 390px 가로 넘침 없음 확인.
