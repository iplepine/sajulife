# 사주 생성 시작 안내 개선

- 요청: 생성 권한 없음이 일반 AI 오류로 보이지 않도록 결제/무료 시작 안내.
- 현재 흐름: 현재 인물의 사주+기질 풀이 한 번 결제 → 권한 기록 → 다음 단계로 이동. 별도 티켓 선택 없음. 베타 무료 모드는 시작 버튼으로 같은 권한 기록.
- 변경: 저장본이 있어도 권한이 없으면 상단에 시작 안내. 무료/유료/결제 준비 중 문구 구분. 권한 조회 실패는 재조회 안내로 분리하고 신규 생성 차단.
- 생성 중 권한이 변경되어 402 PACKAGE_REQUIRED가 반환되면 시작 안내로 전환. 기존 저장본 유지.
- 제외: 가격/결제 방식 변경, 권한 우회, 실제 AI 호출, 커밋/푸시.
- 검증: 타입 검사 및 무료·유료·조회 실패·402 응답을 가짜 응답으로 검사. AI 호출 없음.
- 추가 요청: 무료 베타에서는 별도 시작/구매 기록 없이 즉시 생성 가능. 서버의 개인·융합 생성 검사와 진행 상태 조회가 같은 무료 접근 규칙을 사용한다. 유료/결제 준비 중 모드의 구매 확인 및 AI 생성 한도는 유지. 무료 접근을 위해 주문·영구 구매 기록을 임의 생성하지 않는다.
- 완료 검증: 프로덕션 빌드 통과, 접근/결제 모드 단위 테스트 6개 및 브라우저 테스트 5개 통과. 실제 AI 생성은 실행하지 않음.
- 후속 요청: 대표 요청에 따라 이번 변경을 main에 커밋·푸시.
